# 面向离散时空PDE代理的特征运动传递网络与隐式欧拉自编码器

## 处理对象

- 输入：PDE参数（包括方程系数、狄利克雷边界值）、非结构化网格上的节点坐标、当前时刻非结构化网格上的节点数值

- 输出：下一时刻非结构化网格上的节点数值

## 基本原理

- 将特征点的特征向量构造为一个虚拟的高维速度物理量（特征速度），同时构造虚拟特征质量（特征质量）、虚拟特征坐标（特征坐标），利用质量不变的动量定理，推导出类似自注意力形式的特征更新方法，以此构建特征运动传递网络，拟合时变PDE的变化模式。
- 原始非结构网格一般含有较多的点，信息冗余较大。为了避免大规模节点经过深层网络的巨量计算，提出关键点下采样及相应的上采样方法，将网格点采样至隐空间进行深度的运动传递（Encode），作用完成后再上采样回原始的网格结构（Decoder），形成一个UNET形状的自编码器。
- 将PDE参数嵌入到隐空间中，让运动传递网络学习PDE参数与解函数时间推进之间的关系，解码器将输出下一时刻的解函数值，此时可以利用隐式欧拉法向模型中嵌入PDE方程，提高推理的稳定性。
- 上述采样、运动传递涉及到大权重矩阵的计算，考虑到权重矩阵由两个低秩矩阵相乘得到，因此改进了权重矩阵的归一化方式，分离权重矩阵的矩阵乘法，改变矩阵相乘顺序，大幅减少显存占用。
- 采用离散空间方法计算PDE的偏导项，避免AD计算PDE偏导项的高计算量与训练不稳定问题。计算过程基于变分法实现，将每个节点的邻域通过基函数加权近似，通过节点及领域点构造线性方程，对基函数矩阵进行SVD分解求解线性方程可以拟合出基函数的加权系数。通过加权系数及基函数的形式，即可直接得到偏导项的值。
